# Chip-RISC-S
Chip RISC-S (Super RISC)

# using
in the folder with the chip.c There should be a code.s file with assembly code
compile chip.c (gcc chip.c -o chip) and run (./chip)

# code
1) ram - swap register and RAM cell
2) mov - move num/register value to register
3) add - adder
4) sub - subtraction
5) cmp - examination
6) jeq - jump if equal
7) jlo - jump if low
8) jhi - jump if high
#=========================================
1) registers r0-rF, x00-xFF
2) numbers - hex, xNNNNNN...
3) ram x00-xFF
4) code x000-xFFF
